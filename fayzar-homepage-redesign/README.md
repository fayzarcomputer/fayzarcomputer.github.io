# ফয়জার কম্পিউটার এন্ড ফটোস্ট্যাট — হোমপেজ রি-ডিজাইন প্যাকেজ (Homepage Redesign Standalone)

এই ফোল্ডারে শুধুমাত্র রি-ডিজাইন করা **হোমপেজ এবং এর সাথে সরাসরি সংশ্লিষ্ট সকল অফলাইন ফাইল** আলাদা করে রাখা হয়েছে। অন্য কোনো সাব-পেজ বা সিস্টেম ফাইল রাখা হয়নি, যাতে এটি সহজে বিশ্লেষণ ও পর্যালোচনা করা যায়।

---

## 📁 ফোল্ডারের ফাইল ও ডিরেক্টরি পরিচিতি:
- `index.html` : রি-ডিজাইন করা মূল হোমপেজ (২-কলাম কমপ্যাক্ট হিরো, ভেক্টর কার্ড, ডার্ক মোড, রিভিউ ও এসইও)।
- `css/` :
  - `style.css` : কাস্টম স্টাইলিং ও হাই-কন্ট্রাস্ট ডার্ক মোড ভ্যারিয়েবল।
  - `google-fonts.css` : লোকাল গুগল ফন্টস কনফিগারেশন।
  - `font-awesome/all.min.css` : অফলাইন ফন্ট অসম আইকন সিএসএস।
- `fonts/` : হিন্দ শিলিগুড়ি, আউটফিট সহ প্রয়োজনীয় সকল অফলাইন `.woff2` ফন্টস।
- `webfonts/` : ফন্ট অসমের সবকটি লোকাল আইকন ফাইল।
- `js/` :
  - `vendor/tailwindcss.js` : ১০০% অফলাইন টেইলউইন্ড সিএসএস ইঞ্জিন।
  - `theme-lang.js` : ডার্ক/লাইট মোড এবং বাংলা-ইংরেজি (BN ⇄ EN) দ্বিভাষিক ট্রান্সলেশন ডিকশনারি।
  - `offline-data.js` : নোটিশ ও প্রয়োজনীয় অফলাইন ডাটা।
- `assets/` :
  - `favicon.svg` : অফিসিয়াল ফেভিকন।
  - `images/og-preview.png` : সোশ্যাল শেয়ারিং প্রিভিউ ইমেজ।
- `serve.js` : সাধারণ ও দ্রুতগতির লোকাল নোড সার্ভার স্ক্রিপ্ট (পোর্ট: ৩০৫)।
- `START_HOMEPAGE.bat` : এক ক্লিকে লোকাল সার্ভার ও ব্রাউজার চালু করার স্ক্রিপ্ট।
- `OPEN_DIRECT.bat` : সরাসরি ব্রাউজারে `index.html` ওপেন করার ফাইল।

---

## 🚀 কীভাবে চালু করবেন:
১. **পদ্ধতি ১ (অনুমোদিত):** `START_HOMEPAGE.bat` এ ডাবল ক্লিক করুন। স্বয়ংক্রিয়ভাবে `http://localhost:3005/` চালু হবে।
২. **পদ্ধতি ২:** `OPEN_DIRECT.bat` এ ডাবল ক্লিক করুন। কোনো সার্ভার ছাড়াই সরাসরি ব্রাউজারে ফাইলটি ওপেন হবে।
